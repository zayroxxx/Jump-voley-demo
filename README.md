# Jump Voley · demo

Demo de la app de gestión de la academia **Jump Voley**: pagos y atrasos de alumnos, transferencias con
comprobante, avisos del profe, registro de alumnos y juegos de vóley.

**Abrir la demo:** https://zayroxxx.github.io/Jump-voley-demo/

- Entrar como profesor: botón *Entrar como profesor*, PIN **1234**.
- Entrar como alumno: *Alumno de ejemplo*, o crea una cuenta con tu correo y acéptala desde el profesor.
- Para instalarla en el celular: en Chrome, menú ⋮ → *Instalar app*; en iPhone (Safari), Compartir →
  *Agregar a pantalla de inicio*.

Los datos son de ejemplo y se guardan solo en cada teléfono. *Ajustes → Restaurar datos de ejemplo* vuelve al
inicio.

Esta carpeta contiene solo la app compilada; el código fuente está en un repositorio privado.
